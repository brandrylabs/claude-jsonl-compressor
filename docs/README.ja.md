# Claude JSONL Compressor

[English](../README.md) | [简体中文](README.zh-CN.md) | [日本語](README.ja.md)

Claude Code の長いセッションを短くしても、なぜその判断に至ったかを次の会話に引き継げます。Codex が現在の分岐に沿って、決定とその理由、根拠となる資料、未解決の問いをまとめます。`/rewind` で取り消した分岐は要約から除きます。

## Codex への依頼例

元のセッションを置き換える場合は、先に Claude Code でそのセッションを閉じます。次の依頼文に対象のパスかセッション名を入れて Codex に送ってください。

```text
claude-jsonl-compressor スキルを使って、この Claude JSONL を圧縮してください。
入出力：[.jsonl ファイルのフルパス、または Claude セッションの最終タイトル]
圧縮後は推定10万トークン以内を目標にしてください。現在の分岐の履歴はできるだけ要約に含め、/rewind 用には直近の記録を必要最小限だけ元の形で残してください。巻き戻し地点を残すと目標を超える場合は、トークン数を優先してください。
プロジェクト内のセッションが対象の場合、そのセッションは閉じました。元ファイルをバックアップし、検証が通ったら元のセッションを置き換えてください。単独で書き出した JSONL の場合は、検証済みの結果を別ファイルに保存してください。
完了後に推定トークン数、どこまで巻き戻せるか、出力先とバックアップ先を教えてください。
```

Codex はセッションの最終タイトルで検索します。同名のものがあればフルパスを指定してください。プロジェクトの外に書き出した JSONL も入力に使えます。

## Codex に指定できること

| 設定 | 依頼の例 | 動作 |
|---|---|---|
| 目標サイズ | 「推定10万トークン以内に収めて」 | 指定した上限を目安に圧縮を計画します。次の作業に合わせて数値を変えられます。 |
| 直近の会話と巻き戻し | 「私が始めた直近2ターンは、ツールの結果も含めてそのまま残して」 | 指定したターンを丸ごと保持します。サイズを優先する場合は、巻き戻し地点を省いてよいか伝えます。ファイル変更を巻き戻すには対応する Claude のスナップショットも必要です。 |
| 以前の要約 | 「以前の要約を一字も変えず、新しい内容を追記して」 | 元の文章をそのまま残せます。新旧の内容をまとめ直す方法や、以前の要約にしかない引用を確認して重複を整理する方法も選べます。 |
| 残したい内容 | 「方針を変えた理由と、最後の質問の原文を残して」 | 次に使う資料や決定、検討した選択肢、原文で引き継ぎたい箇所を指定できます。 |
| 長いセッションと再確認 | 「履歴を分けて整理し、重要な結論はサブエージェントに再確認してもらって」 | 長い履歴を分けて処理し、一つの要約にまとめます。必要に応じて追加の確認やサブエージェントによるレビューを依頼できます。 |
| 1回に読み込む量 | 「要約を書くときは、1回の入力を推定10万トークン以内にして」 | 長い履歴を小さな単位に分けられます。この上限は、圧縮後のセッション全体の大きさとは個別に設定します。 |
| 添付資料 | 「画像が含まれるターンはそのまま残して」 | そのターンまで保持範囲を広げ、画像とツールの結果を一緒に残します。未読のメディアをバックアップに保存し、要約に未読と記すよう指定することもできます。 |
| 出力とバックアップ | 「検証後に閉じたセッションを置き換えて」または「別ファイルに保存して」 | 置き換えには検証済みのバックアップを使います。既定の保存先は元ファイルの隣で、名前は `session.jsonl.backup`、次は `session.jsonl.backup1` です。別ファイルに保存する場合は元ファイルも残ります。 |

## インストール

Python 3.10 以降が必要です。npm から導入する場合は Node.js 22 以降も使用します。`npm install --global @brandry/claude-jsonl-compressor@1.2.1` を実行し、パッケージを Codex の `skills/claude-jsonl-compressor` にコピーします。[PowerShell の手順と Linux・macOS の配置先](../README.md#install)
