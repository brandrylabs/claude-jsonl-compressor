# Claude JSONL Compressor

[English](../README.md) | [简体中文](README.zh-CN.md) | [日本語](README.ja.md)

压短 Claude Code 的长会话，下次还能接着讨论当初为什么这样决定。Codex 沿当前分支整理早期对话，保留判断、理由、关键资料和未决问题。已经通过 `/rewind` 放弃的分支不会混入摘要。

## 请 Codex 压缩会话

利用 GPT 与 Claude 的价差，让 GPT 在 Codex 中整理历史，Claude 接续工作时就能少读上下文，也能减少大段历史重新写入缓存的费用。你决定预算和保留内容，Codex 在替换会话前验证结果，让压缩可靠、可控。

要替换原会话时，先在 Claude Code 中关闭它。把下面这段话发给 Codex，填上目标文件或会话名即可。

```text
请使用 claude-jsonl-compressor skill 压缩这个 Claude JSONL。
输入及输出：[填写 .jsonl 文件的完整路径，或 Claude 会话的最终名称]
目标压缩到约 100k token 以内。尽可能把当前分支的历史纳入摘要，仅保留极少量近期原始记录用于 /rewind。如果保留回退点会超出目标，优先满足 token 要求。
如果是项目会话，我已将它关闭。请先备份，运行验证，通过后替换原始会话文件。如果是单独导出的 JSONL，请另存验证后的结果。
完成后告诉我压缩后的估算 token 数、还能回退到哪里，以及输出和备份的位置。
```

Codex 按会话的最终名称查找。有重名时，给出完整路径即可。项目目录外单独导出的 JSONL 也可以作为输入。

## 可以怎样要求 Codex

| 可调选项 | 可以直接这样说 | 会得到什么 |
|---|---|---|
| 目标大小 | “尽量压到 100k token 以内。” | 按给定的估算上限规划压缩。这个数字可以换成适合下一步工作的目标。 |
| 近期对话和回退 | “完整保留最近两轮由我发起的对话，包括工具结果。” | 这些轮次会原样保留。更在意大小时，可明确允许舍弃回退点。回退文件改动还需对应的 Claude 文件快照。 |
| 已有摘要 | “旧摘要逐字保留，把新进展追加在后面。” | 可以锁定旧文，也可以要求重新整合新旧内容，或清理旧摘要里的重复并核对其中独有的引文。 |
| 保留重点 | “留下改换方案的理由，以及最后一个问题的原话。” | 可点名后续需要的资料、决定、曾考虑的选项或需逐字引用的段落。 |
| 长会话和复核 | “分段整理这次会话，再请子智能体复核关键结论。” | Codex 会根据材料判断单次写作预算。能一次写完就一次写，需要分段时尽量保留连续的大段。需要时可要求额外复核，也可以指定子智能体参与。 |
| 单次读入量 | “每次写摘要最多读入约 100k token。” | 长会话可以分成更小的任务。这项限制控制模型每次读多少，与最终会话要压到多大分别设置。 |
| 附件 | “含图片的那一轮原样保留。” | 近期原始记录会向前保留到该轮，连同图片及工具结果一起留下。也可以明确同意把未解析的媒体留在备份里，并在摘要中标为未读。 |
| 输出和备份 | “验证后替换已关闭的项目会话”，或“另存压缩文件”。 | 原地替换使用已经核验的备份。备份默认放在原文件旁，依次命名为 `session.jsonl.backup`、`session.jsonl.backup1`。另存时保留源文件。 |

## 安装

需要 Python 3.10 或更高版本。通过 npm 安装还需要 Node.js 22 或更高版本。运行 `npm install --global @brandry/claude-jsonl-compressor@1.2.2`，将安装好的包复制到 Codex 的 `skills/claude-jsonl-compressor` 目录。[PowerShell 安装命令及 Linux、macOS 路径](../README.md#install)
